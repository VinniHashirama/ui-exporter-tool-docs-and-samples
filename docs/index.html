Instalação uma vez por pessoa

1. Plugin do Figma dev

cd figma-plugin
npm ci --ignore-scripts
npm run build          # gera dist/code.js e dist/ui.html

No Figma: Plugins → Development → Import plugin from manifest... → localize e selecione o manifest.json do repositório do plugin. Cada designer repete esse import uma vez, apontando para a mesma pasta buildada.

2. Pacote Unity dev

  1. Instale via Package Manager: Window → Package Manager → + → Add package from git URL... 
    https://github.com/VinniHashirama/ui-exporter-tool-unity-package.git
    Não precisa travar numa tag — dá para usar a versão mais atual sem problema. Se preferir editar direto, o mesmo endereço vale como valor de com.arvore.uiexporter no Packages/manifest.json.
  2. Projeto novo: Window → TextMeshPro → Import TMP Essential Resources (sem isso nenhum texto renderiza).
  3. Window → Arvore → UI Exporter → Gerar kit placeholder — cria os 15 prefabs canônicos.
  4. Assets → Create → Arvore → UI Exporter → Import Settings — aponte o Rounded Sprite e restrinja Kit Search Folders à pasta do kit.
  5. Assets → Create → Arvore → UI Exporter → Font Map — mapeie cada fonte do Figma para o TMP_FontAsset correspondente.

3. Kit de componentes designer

No plugin, aba Criar kit → Criar kit nesta página. Gera os 14 componentes canônicos, os estilos de cor/texto, e um frame screen/Exemplo pronto para duplicar. Rodar de novo é seguro — o que já existe não é tocado. Precisa de algo fora da lista? Peça o componente canônico ao dono da Library e o prefab equivalente ao dev, com o mesmo nome.

Fluxo de uso — tela rotina

Designer, no Figma

  1. Frame raiz screen/NomeDaTela (PascalCase, sem espaço) — o tamanho dele é a resolução de referência.
  2. Monte com instâncias dos componentes do kit (nunca retângulo + texto por cima).
  3. Auto Layout em listas/HUDs/botões que crescem com texto; constraints no que é posicionado livremente.
  4. Marque: @PlayButton (o código acessa), _notes (não vai para a Unity), hero#img (ilustração/gradiente/sombra vira PNG), title:loc.menu.title (texto traduzível).
  5. Selecione o frame raiz → Plugins → Development → Arvore UI Exporter.
  6. Leia o relatório: erro bloqueia o export, aviso passa mas alguém paga depois. Alvo é zero avisos.
  7. Exporte → baixa NomeDaTela.uiscreen. Entregue ao dev.

Dev, na Unity

  1. Window → Arvore → UI Exporter → Escolher... → selecione o .uiscreen.
  2. Confira o diff: o que será criado, preservado e removido. Remoção é a única operação destrutiva — nada é escrito até confirmar.
  3. Importe. Leia o relatório: componente não mapeado, fonte faltando, aproximação de layout.
  4. Trabalhe sempre no Variant, nunca no _Base:
    Assets/UI/Generated/<Tela>/<Tela>_Base.prefab ← da ferramenta, sobrescrito a cada import Assets/UI/Screens/<Tela>.prefab ← seu, Prefab Variant, nunca tocado
  5. Ligue o código pelos binds: 
    var view = screen.GetComponent<UIViewRefs>();
view.Get<Button>("PlayButton").onClick.AddListener(StartGame);
view.Get<TMP_Text>("CoinLabel").text = coins.ToString();

Designer re-exportou? Repita do passo 8 — o _Base atualiza e o Variant sobrevive.

Fluxo de uso — componente quando ainda não há prefab do jogo

Designer, no Figma

  1. Monte e transforme em Component (Ctrl/Cmd + Alt + K) — frame comum é recusado.
  2. Nomeie com o nome canônico, ex. Button/Primary (variantes vão no Component Set).
  3. Marque slots de conteúdo com $: $label, $icon.
  4. Aba Componente do plugin → confira nome, papel e slots detectados.
  5. Exporte → Button_Primary.uicomponent. Mande ao dev.

Dev, na Unity

  1. Window → Arvore → UI Exporter, escolha o .uicomponent.
  2. Confira nome canônico, papel, slots e quantas telas já instanciam esse componente.
  3. Prefab existente com esse nome (ex. kit placeholder) pede adoção explícita — reconstrói o corpo, a referência sobrevive, mas overrides de texto voltam ao default.
  4. Importe. O prefab aparece em Assets/UI/Generated/Kit/.
Exporte sempre da mesma variante — trocar a origem muda todos os node ids e força refazer o prefab do zero.

Teste de fumaça em 10 minutos

  1. Figma: frame screen/Teste 1080×1920, com um retângulo esticado de fundo.
  2. Um Button/Primary com texto Jogar, nomeado @PlayButton, e um texto @TitleLabel.
  3. Rode o plugin, corrija o linter, exporte.
  4. Importe na Unity: fundo estica, botão clicável, UIViewRefs com os dois binds.
  5. Adicione um script no Variant, peça um re-export com o botão movido, importe de novo — o script tem que sobreviver.

Sem acesso ao Figma, rode contra o pacote de exemplo já versionado: bash tools~/unity-test.sh (no repo do pacote, usa Samples~/HomeMenu.uiscreen).
